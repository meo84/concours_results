# Commit messages

Follow [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/).
If a repository documents a different convention, follow the repository instead.
Don't copy the style of older commits that predate the convention.

# Pull request titles

Use a Conventional Commits prefix in PR titles too, e.g. `refactor: split db helpers and add enums`.
